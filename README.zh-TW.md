# QuadCut 快卡

**四宮格檔案管理器，為快速管理和方便篩選而生。**

[简体中文](README.md) · 繁體中文 · [English](README.en.md) · [日本語](README.ja.md) · [한국어](README.ko.md)

<img src="docs-hero.png" width="320" alt="QuadCut">

剛開始用 Mac 的時候，我每天要處理大量照片和檔案，腦子裡全是同一串念頭：我需要剪下鍵，我需要剪下鍵；我要快速比較檔案大小；我要在 20 張連拍裡一眼挑出對焦最準的那張，順手比比檔案大小；我還要一次批量重新命名 30 張照片……

於是有了 QuadCut —— 在 AI agent 的協助下做出來的、對照片和圖片友善的多宮格檔案管理器。它兼顧一些 Windows 的快速鍵習慣，核心是四格協同、自帶剪下、批量重新命名，以及按住一個鍵就能快速顯示 100% 局部。

除了日常整理檔案，它也為照片和 AI 圖幫點小忙：自動讀出 ISO、快門、光圈，識別並顯示 AI 圖（ComfyUI）的模型、取樣器、提示詞。介面有兩套配色、五種語言。

## 四宮格，四種版面

![格子版面](docs-layout.png)

四格並排，四種擺法，隨時換。

## 剪下就是剪下

`⌘X` 標記，到目標格 `⌘V`，是**移動**，不是複製。

## 按一個鍵，快速查對焦

滑鼠停在預覽圖上，按住 `⌃` 或 `⌥`，或只按中鍵，立刻彈出 100% 原尺寸放大鏡。連拍裡快速判斷對焦準不準、快速篩片，這是最直接的辦法。

## 照片參數快顯

![拍攝參數](docs-photo-exif.png)

選中一張照片，狀態列直接寫著快門、ISO、光圈和尺寸；預覽側欄裡還有鏡頭、焦距和拍攝時間。

## AI 圖的參數，直接讀出來

![AI 圖參數](docs-ai.png)

選中 ComfyUI 或 A1111 生成的圖，模型、步數、CFG、取樣器、提示詞直接讀出來，旁邊一顆按鈕複製全文。

## 批量重新命名

![批量重新命名](docs-batchrename.png)

選中幾項按 `F2`，`PIC##` 就是 `PIC01`、`PIC02`…… 要嘛全成，要嘛一個都不改。

## 外接碟清理：走之前把碟還乾淨

![外接碟清理](docs-external-storage.png)

USB 隨身碟、行動硬碟在 Mac 上用過，會留下 `.DS_Store`、`._xxx`、`.Spotlight-V100` 這些隱藏檔案 —— 換到 Windows 或別人的電腦上，就是一堆看不懂的垃圾。

選單「外存儲 → 移除 macOS 附加檔案並退出」一次清掉再退出，動手前會問你一句。側邊欄那顆 `⏏` 只是普通退出，只退不清。

## 標籤可以拖來拖去

![標籤](docs-tabs.png)

每格最多 6 個標籤，能拖著換位置、拖到別的格子，也能直接拖進左側欄變成書籤。

## 字母快速檢索定位

敲一個字母或數字，直接跳到首字元符合的那一項；中文按拼音首字母。連按同一個鍵就一項項往下走。

## 其他

- 三種檢視：詳細列表 / 圖示格狀 / 大縮圖
- 搜尋（`⌘F`）：目前資料夾及子資料夾，支援 `*` `?` 萬用字元
- 只看圖片、按拍攝時間排序、編輯選單裡的旋轉（JPG / HEIC / TIFF，只改 EXIF，不重新編碼）
- 還原 / 重做、恢復關閉的標籤（`⇧⌘T`）
- 顏色標籤與篩選，和 Finder 是同一份資料
- 五種介面語言、兩套主題
- 路徑網址列、顯示簡介、反選、在這裡打開終端機

## 安裝

**系統需求**：macOS 13 Ventura 或更新，Apple Silicon（M 系列）。目前只發佈 arm64 版本。

1. 下載後把 `QuadCut.app` 拖進「應用程式」
2. 首次開啟如果提示「已損壞，無法打開」—— 這是沒有 Apple 開發者簽章造成的，程式本身沒壞。打開「終端機」跑一次：
   ```bash
   xattr -cr /Applications/QuadCut.app
   ```
   然後再雙擊就能打開。（如果提示的是「無法驗證開發者」，去「系統設定 → 隱私權與安全性」裡點「仍要打開」。）
3. 首次執行請在「系統設定 → 隱私權與安全性 → **完全磁碟存取權**」裡勾上 QuadCut。不勾的話讀不到桌面、下載、文件這些資料夾。

## 快速鍵

| 操作            | 快速鍵                            |
| ------------- | ------------------------------ |
| 返回上一層         | `Tab`（或 `⌘↑`）                  |
| 進入選取項目        | `Enter` / `⌘↓` / 雙擊              |
| 上一頁 / 下一頁     | `⌘[` / `⌘]`                    |
| 重新整理          | `F5`                           |
| 剪下 / 複製 / 貼上  | `⌘X` / `⌘C` / `⌘V`             |
| 製作副本          | `⌘D`                           |
| 移到垃圾桶         | `Del`（PC 鍵帽）/ `⌘⌫`             |
| 新增資料夾         | `⇧⌘N`                          |
| 重新命名 / 批量重新命名 | `F2`                           |
| 顯示簡介          | `⌘R` / `⌥R`                    |
| 還原 / 重做       | `⌘Z` / `⇧⌘Z`                   |
| 全選 / 反選       | `⌘A` / `⇧⌘I`                   |
| 顯示隱藏檔案        | `⌘⇧.`                          |
| 搜尋            | `⌘F`                           |
| 定位到網址列        | `⌘L`                           |
| 切換到第 1–4 格    | `⌘1`–`⌘4`                      |
| 切換檢視          | `⌥⌘1` 列表 / `⌥⌘2` 圖示 / `⌥⌘3` 縮圖 |
| 新增 / 切換標籤     | `⌘T` / `⌃Tab`、`⌃⇧Tab`          |
| 恢復關閉的標籤       | `⇧⌘T`                          |
| 快速預覽          | `空白鍵`                          |
| 按首字母跳轉        | 裸字母 `A`–`Z`、數字 `0`–`9`        |
| 100% 看局部      | 停在預覽圖上，`⌃` / `⌥` / 中鍵         |
| 在這裡打開終端機      | `⌃⌘T`                          |

鍵位是按**鍵盤上印的字**分配的，不是照搬 Windows 的實體位置 —— PC 鍵盤和 Mac 鍵盤都能對上：返回上一層是 `Tab`，刪除是 `Del` / `⌘⌫`。
