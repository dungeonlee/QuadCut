# QuadCut

**빠른 정리와 간편한 선별을 위한 사분할 파일 관리자.**

[简体中文](README.md) · [繁體中文](README.zh-TW.md) · [English](README.en.md) · [日本語](README.ja.md) · 한국어

<img src="docs-hero.png" width="320" alt="QuadCut">

Mac을 처음 쓰기 시작했을 때, 매일 수많은 사진과 파일을 다루면서 머릿속에는 늘 같은 생각뿐이었습니다. 잘라내기 키가 필요해, 잘라내기 키가 필요해. 파일 크기를 빨리 비교하고 싶어. 20장 연사 중에서 초점이 가장 정확한 한 장을 한눈에 고르고 싶어, 겸사겸사 크기도 비교하고. 30장 사진을 한 번에 이름 바꾸고 싶어……

그래서 QuadCut이 생겼습니다. AI agent의 도움을 받아 만든, 사진과 이미지에 친화적인 다중 창 파일 관리자입니다. Windows의 단축키 습관을 일부 이어받았고, 핵심은 네 창의 협업, 기본 내장된 잘라내기, 일괄 이름 변경, 그리고 키 하나만 누르면 바로 보이는 100% 확대입니다.

일상적인 파일 정리 외에도 사진과 AI 이미지에 작은 도움을 줍니다. ISO, 셔터, 조리개를 자동으로 읽어 주고, AI 이미지(ComfyUI)의 모델, 샘플러, 프롬프트를 인식해 보여 줍니다. 테마 두 가지, UI 언어 다섯 가지.

---

## 사분할, 네 가지 레이아웃

![창 배치](docs-layout.png)

네 창을 나란히, 네 가지 배열, 언제든 전환.

## 잘라내기는 정말 잘라내기

`⌘X`로 표시하고 대상 창에서 `⌘V` —— **이동**이지 복사가 아닙니다.

## 키 하나로 초점 확인

미리보기 이미지 위에 마우스를 두고 `⌃` 또는 `⌥`를 누르거나, 가운데 버튼만 눌러도 100% 원본 크기 확대경이 바로 뜹니다. 연사 사진을 선별할 때 초점이 맞았는지 판단하는 가장 직접적인 방법입니다.

## 촬영 정보 바로 보기

![촬영 정보](docs-photo-exif.png)

사진을 선택하면 상태 막대에 셔터, ISO, 조리개, 크기가 바로 나옵니다. 미리보기 사이드바에는 렌즈, 초점 거리, 촬영 시각도 있습니다.

## AI 이미지 파라미터, 그대로 읽어내기

![AI 이미지 파라미터](docs-ai.png)

ComfyUI나 A1111로 만든 이미지를 선택하면 모델, 스텝, CFG, 샘플러, 프롬프트가 그대로 읽히고, 옆의 버튼 하나로 전체를 복사할 수 있습니다.

## 일괄 이름 변경

![일괄 이름 변경](docs-batchrename.png)

몇 개를 선택하고 `F2`. `PIC##`은 `PIC01`, `PIC02`…… 전부 바뀌거나, 하나도 바뀌지 않거나 둘 중 하나입니다.

## 외장 디스크 정리: 돌려주기 전에 깨끗하게

![외장 디스크 정리](docs-external-storage.png)

USB 메모리나 외장 하드를 Mac에서 쓰면 `.DS_Store`, `._xxx`, `.Spotlight-V100` 같은 숨은 파일이 남습니다. Windows나 남의 컴퓨터로 옮기면 영문 모를 쓰레기 더미가 됩니다.

메뉴의 "외장 저장소 → macOS 부가 파일 제거 후 꺼내기"를 한 번 실행하면 싹 지우고 꺼냅니다. 실행 전에 한 번 물어봅니다. 사이드바의 `⏏`는 일반 꺼내기라서 지우지 않고 꺼내기만 합니다.

## 탭은 끌어서 옮깁니다

![탭](docs-tabs.png)

창 하나에 최대 6개 탭. 끌어서 순서를 바꾸고, 다른 창으로 옮기고, 왼쪽 사이드바로 끌면 북마크가 됩니다.

## 글자로 빠르게 찾기

글자나 숫자를 하나 입력하면 그 글자로 시작하는 항목으로 바로 점프합니다. 중국어는 병음 첫 글자로 맞춥니다. 같은 키를 계속 누르면 다음 항목으로 넘어갑니다.

## 그 밖에

- 세 가지 보기: 자세한 목록 / 아이콘 그리드 / 큰 썸네일
- 검색(`⌘F`): 현재 폴더와 하위 폴더, `*` `?` 와일드카드 지원
- 이미지만 보기, 촬영 시각으로 정렬, 편집 메뉴의 회전(JPG / HEIC / TIFF, EXIF만 변경, 재인코딩 없음)
- 실행 취소 / 다시 실행, 닫은 탭 복원(`⇧⌘T`)
- 컬러 태그와 필터, Finder와 같은 데이터 공유
- UI 언어 다섯 가지, 테마 두 가지
- 경로 주소 막대, 정보 보기, 선택 반전, 여기서 터미널 열기

## 설치

**요구 사항**: macOS 13 Ventura 이상, Apple Silicon(M 시리즈). 현재는 arm64 빌드만 배포합니다.

1. 내려받은 `QuadCut.app`을 "응용 프로그램"으로 끌어다 놓습니다.
2. 첫 실행에서 "손상되었기 때문에 열 수 없습니다"가 뜬다면 —— Apple 개발자 서명이 없어서 그런 것이고, 앱 자체는 멀쩡합니다. "터미널"을 열고 한 번 실행하세요:
   ```bash
   xattr -cr /Applications/QuadCut.app
   ```
   그다음 다시 더블클릭하면 열립니다. ("개발자를 확인할 수 없습니다"가 뜨면 "시스템 설정 → 개인정보 보호 및 보안"에서 "그래도 열기"를 누르세요.)
3. 첫 실행 시 "시스템 설정 → 개인정보 보호 및 보안 → **전체 디스크 접근 권한**"에서 QuadCut을 켜 주세요. 켜지 않으면 데스크톱, 다운로드, 문서 폴더를 읽을 수 없습니다.

## 단축키

| 동작             | 단축키                                  |
| -------------- | ------------------------------------ |
| 상위 폴더로        | `Tab` (또는 `⌘↑`)                      |
| 선택 항목 열기      | `Return` / `⌘↓` / 더블클릭               |
| 뒤로 / 앞으로      | `⌘[` / `⌘]`                          |
| 새로고침           | `F5`                                 |
| 잘라내기 / 복사 / 붙여넣기 | `⌘X` / `⌘C` / `⌘V`                 |
| 복제             | `⌘D`                                 |
| 휴지통으로 이동      | `Del` (PC 키) / `⌘⌫`                  |
| 새 폴더           | `⇧⌘N`                                |
| 이름 변경 / 일괄 이름 변경 | `F2`                             |
| 정보 보기          | `⌘R` / `⌥R`                          |
| 실행 취소 / 다시 실행  | `⌘Z` / `⇧⌘Z`                         |
| 전체 선택 / 선택 반전  | `⌘A` / `⇧⌘I`                         |
| 숨은 파일 보기      | `⌘⇧.`                                |
| 검색             | `⌘F`                                 |
| 주소 막대로 이동     | `⌘L`                                 |
| 1–4번 창으로 전환   | `⌘1`–`⌘4`                            |
| 보기 전환          | `⌥⌘1` 목록 / `⌥⌘2` 아이콘 / `⌥⌘3` 썸네일 |
| 새 탭 / 탭 전환    | `⌘T` / `⌃Tab`, `⌃⇧Tab`               |
| 닫은 탭 복원       | `⇧⌘T`                                |
| 빠른 보기          | `스페이스`                              |
| 첫 글자로 점프      | 그냥 `A`–`Z`, 숫자 `0`–`9`               |
| 100%로 보기      | 미리보기 위에서 `⌃` / `⌥` / 가운데 버튼       |
| 여기서 터미널 열기    | `⌃⌘T`                                |

키는 **키캡에 인쇄된 글자**를 기준으로 배치했고, Windows의 물리적 위치를 그대로 옮긴 것이 아닙니다 —— PC 키보드와 Mac 키보드 모두 맞습니다: 상위 폴더로는 `Tab`, 삭제는 `Del` / `⌘⌫`.
